尊敬的编辑：

我们提交稿件**《8 bit 就地权重投影的代价曲线：间隔、覆写与随机舍入》**，申请作为研究论文审理。

面向部署的量化感知训练（QAT）通常在训练中把权重就地覆写到 int8 网格上，并维护一份 EMA 影子。投影间隔与影子写入时机在实践中多凭经验设定，而用来判断它们的指标常常正是按构造不携带信息的那些。本文在固定配方下把这些选择测出来，报告四件事。

1. **一条剂量曲线。** 相对关闭投影，部署 MAE 在间隔 20 上高 0.0047、在间隔 1 上高 0.0185（1,556 张未参与选轮的图像、8 个初始 seed、配对、以 run 为推断单位）。关闭投影是我们在只量化权重的 8 bit 设置下找到的最优点，在主配置与厂商 NPU 链上都成立。
2. **归因与一条零成本修法。** 代价属于就地覆写这一步，而不属于权重停在网格上：每步伪量化但不覆写（STE）与关闭投影未检测到差异（−0.0001），而在覆写时把就近舍入换成随机舍入，网格、间隔与训练预算都不变，代价几乎全部消失（0.0183 → 0.00004）。
3. **一条等价性边界。** 平均顺序使导出权重的相对 L2 移动 4.3–9.1 %，且该位移在导出再量化后仍然保留；但函数侧后果落在我们预先指定的 0.0016 等价界之下（MDE 0.000383）。我们把它报告为本设计能够证明的界，而不是两种顺序等价的证明。
4. **一份可执行的协议。** 评估 8 bit 部署训练的五条规则，其中一条作为前提而非发现来陈述：当训练期投影与部署量化器共用同一网格时，导出期再量化幂等，8 bit 量化余弦这类保真度指标按构造不携带信息，评估必须报告部署量化之后测得任务指标。

间隔结论另在厂商 NPU 工具链、第二条后端（OpenVINO + NNCF）与两条外推轴（ResNet-18 架构、KonIQ-10k 数据集）上复核；这些只作方向性观察，我们不把它们当作独立复现。

本文不提新的 QAT 算法，也不把随机舍入或无主副本的直接量化训练据为己有：两者都引自文献，我们的贡献是在同一配方内对它们的效应做受控测量，并给出可复现的评估协议。
